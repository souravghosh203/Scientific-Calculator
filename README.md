# 🧮 Scientific Calculator

> A modern, responsive, and feature-rich Scientific Calculator built with React and Vite — designed for accurate calculations, smooth interaction, and a clean user experience.

## 🚀 Live Demo

🔗 **[Open Scientific Calculator](https://5060-iauq4oo5kakt5uaa4fa5a-8f57ffe2.sandbox.novita.ai/)**

---

## ✨ Features

- 🧮 **Scientific Calculations** — Perform a wide range of mathematical and scientific operations.
- 🧠 **Smart Calculation Engine** — Handles mathematical expressions with validation and error handling.
- 🕘 **Calculation History** — Review and manage previous calculations.
- 💾 **Memory Functions** — Store, recall, add, and clear values when needed.
- ⚡ **Fast & Lightweight** — Powered by React and Vite for a smooth experience.
- 📱 **Fully Responsive** — Works across desktop, tablet, and mobile devices.
- 🎨 **Modern UI** — Clean, intuitive, and user-friendly interface.
- 🧩 **Modular Architecture** — Organized React components for maintainability and scalability.
- 🛡️ **Input Validation** — Prevents invalid expressions and provides clear error feedback.
